## 🎯 Tentang Proyek

Vinss Store Website New adalah platform toko online modern yang dibangun dengan teknologi web terkini. Website ini dirancang untuk memberikan pengalaman berbelanja yang mudah, cepat, dan menyenangkan bagi pengguna.

### Keunggulan:
- ⚡ **Performance** - Loading cepat dan optimal
- 📱 **Responsive** - Tampilan sempurna di semua perangkat
- 🎨 **Modern Design** - UI/UX yang menarik dan intuitif
- 🔒 **Secure** - Keamanan data terjamin

---

## ✨ Fitur Utama

- 🏪 **Katalog Produk** - Tampilan produk yang menarik dan terorganisir
- 🔍 **Pencarian** - Sistem pencarian produk yang cepat dan akurat
- 🛒 **Shopping Cart** - Keranjang belanja yang mudah digunakan
- 💳 **Checkout** - Proses pembayaran yang aman dan mudah
- 📊 **Dashboard** - Panel kontrol untuk mengelola produk
- 🌐 **Multi-Platform** - Dapat diakses dari berbagai perangkat
- 🎨 **Custom Design** - Desain yang dapat disesuaikan
- ⚙️ **Easy Configuration** - Konfigurasi yang mudah dan fleksibel

---

## 🛠️ Teknologi

Proyek ini dibangun menggunakan:

### Frontend:
- **HTML5** - Struktur halaman web
- **CSS3** - Styling dan animasi
- **JavaScript** - Interaktivitas dan logika aplikasi

### Deployment:
- **Vercel** - Hosting dan deployment otomatis

---

## 📦 Instalasi

### Prasyarat

Pastikan Anda telah menginstal:
- Web browser modern (Chrome, Firefox, Safari, Edge)
- Text editor (VS Code, Sublime Text, dll)
- Git

### Langkah Instalasi

1. **Clone repository**
   ```bash
   git clone https://github.com/Vinss-Store/Website-New.git
   ```

2. **Masuk ke direktori proyek**
   ```bash
   cd Website-New
   ```

3. **Buka dengan text editor**
   ```bash
   code .
   ```

4. **Jalankan dengan Live Server**
   - Jika menggunakan VS Code, install extension "Live Server"
   - Klik kanan pada `index.html` → "Open with Live Server"
   - Atau langsung buka file `index.html` di browser

---

## 🚀 Penggunaan

### Development

Untuk menjalankan website secara lokal:

```bash
# Menggunakan Live Server (VS Code Extension)
# Atau gunakan local server lainnya seperti:

# Python 3
python -m http.server 8000

# PHP
php -S localhost:8000

# Node.js (http-server)
npx http-server
```

Kemudian buka browser dan akses:
```
http://localhost:8000
```

### Deployment

Website ini sudah di-deploy di:
- **Production**: [https://vinss-botz.vercel.app](https://vinss-botz.vercel.app)

Untuk deploy sendiri ke Vercel:

1. Fork repository ini
2. Buat akun di [Vercel](https://vercel.com)
3. Import repository dari GitHub
4. Deploy otomatis akan berjalan
